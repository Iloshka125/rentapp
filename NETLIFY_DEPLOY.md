# Деплой на Netlify

## Подготовка к деплою

### 1. Настройка переменных окружения
В панели Netlify добавьте следующие переменные окружения:
- `VITE_API_BASE_URL` = `https://91.92.42.248`
- `VITE_APP_ENV` = `production`
- `VITE_APP_NAME` = `Аренда инструментов`

### 2. Настройка сборки
- **Build command**: `npm run build`
- **Publish directory**: `dist`
- **Node version**: `18`

## Способы деплоя

### Способ 1: Через Git (рекомендуется)
1. Подключите репозиторий к Netlify
2. Настройте автоматический деплой при push в main ветку
3. Netlify автоматически соберет и задеплоит проект

### Способ 2: Ручной деплой
1. Выполните сборку локально:
   ```bash
   npm run build
   ```
2. Загрузите папку `dist` в Netlify через drag & drop

### Способ 3: Через Netlify CLI
1. Установите Netlify CLI:
   ```bash
   npm install -g netlify-cli
   ```
2. Войдите в аккаунт:
   ```bash
   netlify login
   ```
3. Соберите проект:
   ```bash
   npm run build
   ```
4. Задеплойте:
   ```bash
   netlify deploy --prod --dir=dist
   ```

## Настройки проекта

### CORS
Убедитесь, что сервер `https://91.92.42.248` настроен для работы с CORS:
- Добавьте домен Netlify в список разрешенных origins
- Настройте заголовки CORS на сервере

### API проксирование
В файле `netlify.toml` настроено проксирование API запросов:
- Запросы к `/api/*` перенаправляются на `https://91.92.42.248/api/*`

## Проверка после деплоя

1. Откройте сайт в браузере
2. Проверьте работу поиска и фильтров
3. Убедитесь, что API запросы работают корректно
4. Проверьте загрузку изображений

## Возможные проблемы

### CORS ошибки
Если возникают CORS ошибки, добавьте в `netlify.toml`:
```toml
[[headers]]
  for = "/*"
  [headers.values]
    Access-Control-Allow-Origin = "*"
```

### Проблемы с роутингом
Убедитесь, что настроено перенаправление для SPA:
```toml
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### Проблемы с API
Проверьте, что сервер `https://91.92.42.248` доступен и настроен для работы с фронтендом.
