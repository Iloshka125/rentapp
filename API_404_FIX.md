# 🔧 Исправление ошибки 404 для API

## Проблема
```
GET https://91.92.42.248/product/getAll 404 (Not Found)
```

## ✅ Решение

### 1. Проблема была в том, что:
- Запросы шли напрямую на `https://91.92.42.248` вместо использования проксирования
- Edge Functions пытались обратиться к HTTPS серверу, который не поддерживает HTTPS

### 2. Что исправлено:
- **Edge Functions** теперь обращаются к `https://91.92.42.248` (https) с полным путем `/api/*`
- **Конфигурация API** использует относительные пути `/api/*`
- **Проксирование** работает через Netlify Edge Functions
- **Путь API** сохраняется полностью: `/api/product/getAll` → `https://91.92.42.248/api/product/getAll`

### 3. Как это работает:
1. Фронтенд делает запрос на `/api/product/getAll`
2. Netlify перенаправляет на Edge Function
3. Edge Function обращается к `https://91.92.42.248/api/product/getAll`
4. Ответ возвращается через HTTPS

## 🚀 Деплой

### 1. Пересоберите проект:
```bash
npm run build
```

### 2. Загрузите в Netlify:
- Перетащите папку `dist` в Netlify
- Или подключите Git репозиторий

### 3. Настройте переменные окружения:
В панели Netlify → Site settings → Environment variables:
```
VITE_API_BASE_URL = (оставить пустым)
```

### 4. Включите Edge Functions:
В панели Netlify → Site settings → Functions:
- Убедитесь, что Edge Functions включены

## 🔍 Проверка

После деплоя проверьте:
- ✅ Запросы идут на `/api/*` (относительные пути)
- ✅ Нет ошибок 404
- ✅ API данные загружаются корректно
- ✅ В консоли браузера нет ошибок Mixed Content

## 📝 Примечания

- Сервер `91.92.42.248` остается https
- Проксирование обеспечивает HTTPS для фронтенда
- Edge Functions работают на серверах Netlify (HTTPS)
- Все запросы к API идут через безопасное соединение
