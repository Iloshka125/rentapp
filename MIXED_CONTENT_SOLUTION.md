# 🔧 Решение проблемы Mixed Content без HTTPS

## Проблема
Браузер блокирует https запросы с HTTPS сайта из соображений безопасности.

## ✅ Решения (выберите одно)

### Решение 1: Настройка браузера (временное)
1. Откройте Chrome
2. Перейдите в `chrome://flags/#block-insecure-private-network-requests`
3. Установите "Disabled"
4. Перезапустите браузер

### Решение 2: Использование Edge Functions (рекомендуется)
1. Убедитесь, что в Netlify включены Edge Functions
2. Пересоберите проект: `npm run build`
3. Загрузите в Netlify

### Решение 3: Прямые https запросы
1. Установите переменную `VITE_API_BASE_URL=https://91.92.42.248`
2. Пересоберите проект: `npm run build`
3. Загрузите в Netlify

### Решение 4: Использование https версии сайта
1. Создайте https версию сайта
2. Используйте поддомен типа `https://discway.netlify.app`

## 🚀 Быстрое решение

### Вариант A: Настройка браузера
```bash
# Запустите Chrome с отключенной проверкой Mixed Content
chrome --disable-web-security --user-data-dir=/tmp/chrome_dev
```

### Вариант B: Использование https
1. В настройках Netlify установите:
   ```
   VITE_API_BASE_URL=https://91.92.42.248
   ```
2. Пересоберите и задеплойте

### Вариант C: Локальный прокси
1. Создайте локальный прокси-сервер
2. Направьте API запросы через него

## 🔍 Проверка
После применения любого решения:
- ✅ API запросы работают
- ✅ Данные загружаются
- ✅ Нет ошибок в консоли

## 📝 Примечания
- Решение 1 работает только локально
- Решение 2 требует поддержки Edge Functions
- Решение 3 может не работать в некоторых браузерах
- Решение 4 требует настройки DNS
