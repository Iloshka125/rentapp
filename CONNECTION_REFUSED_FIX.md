# 🔧 Исправление ошибки ERR_CONNECTION_REFUSED

## Проблема
```
Failed to load resource: net::ERR_CONNECTION_REFUSED
Ошибка при загрузке владельца товара: TypeError: Failed to fetch
```

## ✅ Решение

### 1. Проблема была в том, что:
- Edge Functions не работают или не настроены
- Сложная система проксирования вызывала ошибки
- Netlify не мог подключиться к Edge Functions

### 2. Что исправлено:
- **Убрали Edge Functions** - используем простые redirects
- **Прямое проксирование** через netlify.toml
- **Упростили apiService** - убрали лишние проверки
- **Обновили _redirects** - для совместимости

### 3. Как теперь работает:
1. **Фронтенд**: `/api/product/getAll`
2. **Netlify redirect**: `https://91.92.42.248/api/product/getAll`
3. **Сервер**: получает запрос напрямую

## 🚀 Деплой

### 1. Пересоберите проект:
```bash
npm run build
```

### 2. Загрузите в Netlify:
- Перетащите папку `dist` в Netlify
- Или подключите Git репозиторий

### 3. Настройте переменные окружения:
В панели Netlify → Site settings → Environment variables:
```
VITE_API_BASE_URL = (оставить пустым)
```

## 🔍 Проверка

После деплоя проверьте:
- ✅ Запросы идут на `/api/*` (относительные пути)
- ✅ Нет ошибок ERR_CONNECTION_REFUSED
- ✅ API данные загружаются корректно
- ✅ В консоли браузера нет ошибок

## 📝 Примечания

- Используется простое проксирование через redirects
- Не нужны Edge Functions или сложные настройки
- Все запросы идут через HTTPS на фронтенде
- Проксирование работает на уровне Netlify
